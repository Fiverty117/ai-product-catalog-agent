# Catalog Image Skill

## Purpose
Guide Codex when implementing or reviewing the high-fidelity catalog image pipeline.

## Principles
- Preserve the original upload permanently.
- Edited catalog image is a separate derived asset.
- Prefer high-fidelity editing that maintains packaging identity, logo, label, proportions and visible text.
- Improve background, lighting and professional presentation without redesigning the product.
- Review UI must allow original-vs-edited comparison.
- Suspected meaningful discrepancies should route to review, not silent publication.
- Do not impose pixel-identity as a requirement if it prevents legitimate lighting/presentation improvements.
